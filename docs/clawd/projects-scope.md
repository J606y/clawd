# 项目与专属记忆：模式边界

用户确定方向：将文件夹功能改为项目；同项目会话聚合；每项目除全局记忆外拥有独立专属记忆。普通聊天已有普通模式，不需要无目录项目。

已明确的产品契约：普通模式没有项目归属，使用全局记忆；项目模式必须绑定真实工作目录，使用全局记忆与该项目专属记忆。同项目对话放在一起。创建项目可以选择已有目录或由系统创建独立目录，具体创建交互在实现时保持现有界面风格。绑定目录不自动构成安全沙箱。

状态：工作目录绑定方向已确认，功能尚未实现或验证。当前不迁移或删除任何已有文件夹、会话和记忆。

实现原则：优先复用并扩展核心已有项目能力；项目是核心持久化实体，不只改前端名称，会话通过稳定 project_id 归属。项目记忆不读取其他项目内容；写入明确作用域，不能默默提升为全局记忆。子代理及后台续跑继承所属会话项目身份与工作目录，不依赖浏览器当前选中项。权限、并发与记忆变更通过核心接口处理。同项目共享长期记忆不等于将全部历史聊天塞入每个会话。

既有面板布局与出字动画保持；文件夹归属升级须有可回滚迁移并保留原会话ID。旧文件夹尚无目录映射，迁移时不得猜测绑定已有代码库，也不得在未授权时操作生产数据。删除/归档项目不得隐式删除会话、记忆或工作目录。运行中切换项目、跨项目移动会话、全局/项目记忆冲突和提示缓存策略需冻结后实现，不能在已有回合中偷偷更换项目上下文。

协调：面板绑定代理保持旧文件夹接口兼容，暂停文件夹schema结构性改造；其它clawd整合继续。下一实施检查点核对核心项目、cwd传播与记忆作用域，形成具体接口和迁移方案后独立落实与验收。
